# Estándar visual del carrito de herramientas

Catálogo profesional e interactivo compatible con GitHub Pages. Conserva el acomodo lateral de Genially e incluye nueve cajones, puntos interactivos, fichas técnicas, búsqueda y vista de lista.

## Publicar

1. Sube `index.html`, `app.js`, `styles.css` y la carpeta `images` a la raíz del repositorio.
2. En GitHub abre **Settings → Pages**.
3. En **Build and deployment** selecciona **Deploy from a branch**.
4. Elige la rama `main`, la carpeta `/root` y pulsa **Save**.
5. Espera unos minutos y abre:

   `https://emanahd19-rgb.github.io/inventario-carrito-herramientas/`

No requiere Node.js, instalación ni compilación.
